# Rohan Realty Knowledge Hub (`context/`)

This directory serves as the centralized persistent context and knowledge hub for the `rohanrealty.co.za` web platform.

## Structure
- `business_intel.md`: Business reality, target demographic (HNWIs), UVPs, legal entities (Blue Ocean Realty affiliation), contact channels, and social media links.
- `tech_stack.md`: Tech stack, design tokens, typography, navbar constraints, responsive geometry, schema markup rules.
- `active_session.md`: Living record of current sprint progress, decisions made, and upcoming implementation milestones.
- `docs/`: Design documents, specifications, and architecture RFCs.
- `raw/`: Drop-zone for raw incoming client assets, photos, PDFs, and briefs (gitignored).
